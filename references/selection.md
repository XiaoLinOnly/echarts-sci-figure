# 选图决策

选图的目标不是"画得好看"，而是**让读者在 3 秒内看出数据的结构**。依次过四关：
硬约束 → 数据形态 → 候选分级 → 打分。任何一关不通过就不要往下走。

## 第 0 关：硬约束（不满足就换图，不给例外）

| 约束 | 判据 |
| --- | --- |
| 不用 3D | 任何 3D 柱/饼/散点。透视会引入长度错觉，期刊图几乎不接受 |
| 饼图 ≤ 5 片且只有一层 | 超过 5 片或需要两级 → 100% 堆叠条 / 矩形树图 / 旭日图 |
| 柱状图 y 轴必须从 0 起 | 截断柱长会把 2% 差异画成 2 倍。要强调差异改用点图 + 误差棒 |
| 双 y 轴仅限单位不同且趋势需并列 | 能用两个 panel 就别用双轴；用双轴必须两侧刻度配色与系列一致 |
| 发散色阶只用于有符号量 | 相关系数、差值、log2FC。无符号量用单色渐变，绝不用彩虹（jet 类色阶） |
| 雷达图不做排名 | 雷达的多边形面积随轴顺序变化，且不可比绝对值；只用于"同一对象多维画像" |
| 不隐藏 n | 每组样本量写进图注或轴标签；n<5 时优先画原始点而不是均值柱 |
| 堆叠条不用于含负值数据 | 正负混合堆叠会让读者无法还原总量 |

## 第 1 关：数据形态 → 图族

先跑 `scripts/profile_data.py` 拿到列类型，再按下表定位。表中"首选"是在该形态下信息损失最小的一类。

| 变量结构 | 首选 | 备选（更省空间/更强调） | 避免 |
| --- | --- | --- | --- |
| 1 类别 + 1 数值，类别 ≤ 12 | 柱状图 | 点图/棒棒糖（类别多、标签长）；误差棒（有不确定度） | 饼图（若类别是整体划分且 ≤5 片可用） |
| 1 类别 + 1 数值，类别 > 12 | 横向点图 / 棒棒糖 | 横向条形（标签长时）；热图（若还能再分维度） | 竖向柱（标签必然重叠） |
| 1 类别 + 1 数值 + 不确定度 | 柱/点 + 误差棒 | 森林图（效应量 + 置信区间，多条目对比） | 只画均值不画误差 |
| 2 类别 + 1 数值 | 分组柱状图 | 热图（水平数多）；小倍数面板（组内有子结构） | 3D 柱；堆叠（若需比较各格绝对值） |
| 1 类别 + 多指标（需归一化） | 雷达图（2–4 个对象） | 平行坐标（对象多、轴多，不用归一化） | 雷达 >4 个对象（线团） |
| 时间 + 1 数值 | 折线 | 面积图（单系列强调累积）；散点+趋势线（采样不均） | 折线连不连续的时间点而不标注断点 |
| 时间 + 多系列（同一量纲） | 多线折线 | 小倍数（系列 >6）；堆叠面积（强调总量与构成） | 6 条以上彩色线挤一张图 |
| 时间 + 排名变化 | 凹凸图（bump） | 斜率图（只有两个时点） | 多折线（交叉处无法追踪） |
| 时间 + 构成流动 | 主题河流图 | 100% 堆叠面积 | 饼图 × 多个时点 |
| 2 数值 | 散点 | 密度色阶（过密）；相关系数标注 | 折线（x 不是时间时不应连线） |
| 3 数值 | 气泡（第三维=大小） | 颜色映射第三维 + 色标 | 大小与颜色同时编码两个变量（不可读） |
| ≥4 数值（高维） | 散点矩阵 | 平行坐标；相关性热图（只看两两关系） | 降维图（除非确有降维方法且在图注说明） |
| 分布（单变量） | 直方图 | 箱线图（多组对比）；抖动散点（n 小） | 只报均值±SD 而不给分布 |
| 分布（多组） | 箱线图 + 原始点 | 小提琴图（需 matplotlib 侧）；蜂群图 | 只有箱体没有 n |
| 整体构成（单时点） | 100% 堆叠条 | 矩形树图（层级）；旭日图（两级） | 饼图 >5 片 |
| 层级构成 | 矩形树图 | 旭日图（需看到层级路径）；树图（层级浅且有顺序） | 饼图嵌套 |
| 流向 / 转移 | 桑基图 | 和弦图（对称关系、类别少） | 用箭头折线手绘流向 |
| 网络关系 | 力导向图 | 环形布局（节点有分组） | 节点 >50 的力导向图（读不出结构） |
| 矩阵数值（混淆、相关） | 热图 | 气泡矩阵（数值差异大时） | 表格直接截图 |
| 阶段转化（单调递减） | 漏斗图 | 水平条形 + 转化率标注 | 非单调数据用漏斗 |
| 单指标 vs 目标 | 点 + 目标参考线 | 仪表盘（仅用于演示，不用于论文） | 仪表盘放进期刊图 |
| 贡献分解（增量/减量） | 瀑布图 | 桥接图 | 堆叠柱（看不出哪段是负向） |

## 第 2 关：候选分级

对同一份数据，**必须给出三个候选**，分级标准是"偏离常规的程度"，不是"好看程度"：

| 档位 | 定义 | 什么时候给 |
| --- | --- | --- |
| A 稳妥 | 该数据形态的首选图，审稿人不用解释 | 永远给 |
| B 更优 | 解决首选图的具体缺陷（标签重叠、过密、看不出排名） | 数据有该缺陷时必给 |
| C 创意 | 换了一个编码通道（位置→角度/面积/颜色）或换了叙事视角 | 数据满足其成立条件时给，并写明代价 |

输出格式（对用户）：

```
候选 A（稳妥）：分组柱状图
  为什么：两组配方 × 三个温度，绝对值可直接比较
  代价：12 根柱子，读者要逐对扫视
  示例：bar-simple / bar-y-category

候选 B（更优）：点图 + 误差棒
  为什么：差异只有 3%，柱长看不出，点位置能看出；误差棒给出 n=5 的离散度
  代价：不直观呈现"总量"
  示例：custom-error-scatter

候选 C（创意）：平行坐标
  为什么：5 个力学指标同时呈现，能看出配方在指标间的 trade-off 走向
  成立条件：5 个指标必须先归一化到 0–1，且读者关心的是"折线交叉"而非具体数值
  代价：无法读出单个指标的精确值，需配一张数值表
  示例：parallel-simple
```

C 档必须写"成立条件"，因为创意图的失败几乎都来自条件不成立。不要用"更有设计感"当理由。

## 第 3 关：打分

按四项打分（1–5），加权后取最高者为推荐项：

| 维度 | 权重 | 5 分 | 3 分 | 1 分 |
| --- | --- | --- | --- | --- |
| 准确性 | 40% | 编码通道与数据类型匹配，不歪曲比例 | 有轻微信息损失（如面积编码） | 会误导（截断轴、面积当长度） |
| 可读性 | 30% | 不看正文也能懂主结论 | 需要图注解释编码 | 需要口头讲解 |
| 信息密度 | 15% | 一图承载多维且不拥挤 | 只承载一维 | 大量留白或过载 |
| 新颖度 | 15% | 少见但读者一看就懂 | 常见 | 陈词滥调（默认柱状+彩虹色） |

准确性低于 4 分的方案直接淘汰，不管其他项多高。新颖度永远不能抵消准确性——这是期刊图，不是信息图比赛。

## 期刊约束清单

出图前逐项确认（不确定就问用户目标期刊）：

- 栏宽：单栏 85 mm、1.5 栏 114 mm、双栏 174 mm；高度通常 ≤ 234 mm
- 字号：缩放后正文 7–9 pt，轴标题 8–9 pt，面板标号 (a)(b) 8 pt 粗体
- 线宽：坐标轴线 ≥ 0.5 pt，数据线 ≥ 1 pt（本 skill 主题默认 1.6 px ≈ 1.2 pt）
- 颜色：色盲安全（Okabe-Ito），且在灰度打印下仍可区分（明度差 ≥ 20%）
- 矢量优先：SVG/PDF；位图 ≥ 300 dpi，线条图建议 600 dpi
- 单位与有效数字：轴标题带单位 `(MPa)`，刻度有效数字一致
- 图注独立可读：写清 n、误差含义（SD/SEM/95%CI）、统计检验

## 何时离开 ECharts

ECharts 擅长坐标轴类、矩阵类、流与层级。以下情况改用别的工具，不要硬做：

- 统计分布图（小提琴、raincloud、带边际分布的散点）→ matplotlib / seaborn，或 `nature-figure` skill
- 需要真正的统计标注（显著性括号、p 值连接线）→ matplotlib
- 需要与 LaTeX 字体完全一致 → matplotlib + PGF
- 地理空间投影 → ECharts 的 geo/map 可以，但需要底图 GeoJSON，成本高
